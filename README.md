# 🏥 Medinova — Bootstrap Hospital Website

> A clean, responsive hospital website built with Bootstrap 5. Features a complete medical service showcase, appointment booking form, pricing plans, doctor profiles, patient testimonials, and a medical blog — all styled with a professional teal brand color.

## ✨ Features

- **Sticky Navbar** — Bootstrap responsive navigation with hamburger on mobile
- **Top Contact Bar** — phone, email and social icons (desktop only)
- **Hero Section** — full screen background image with headline and CTA buttons
- **About Section** — side by side layout with image and 4 highlight icon badges
- **Services Section** — 6 medical service cards in Bootstrap grid
- **Appointment Form** — department, doctor, name, email, date and time fields
- **Pricing Plans** — 4 medical packages in Owl Carousel with custom navigation
- **Doctors Team** — 3 doctor profiles in Owl Carousel with social links
- **Find a Doctor** — department dropdown + keyword search bar
- **Testimonials** — patient reviews in Owl Carousel with dot indicators
- **Blog Posts** — 3 latest medical articles with view and comment counts
- **Footer** — 4-column layout with contact, quick links, newsletter and social
- **Back to Top** — smooth scroll button fixed to bottom right
